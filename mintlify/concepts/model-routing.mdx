## Choose a model

```bash
forge models --refresh --json
forge route "Update the parser" --provider PROFILE --json
forge config model --exact MODEL_ID --profile PROFILE
```

ForgeKit reports `unrated` on a new repository. An operator can select a deployment explicitly. A configured selection identifies the exact wire ID and carries no inferred score. Native coding clients manage their own model selection.

## Compare repository outcomes

```bash
forge route outcome "Update the parser" --provider PROFILE --model REGISTRY_ID --pass --cost 0.12 --verify-run RUN_ID --workload repair
forge route universal "Check pagination" --provider PROFILE --workload repair --objective target:0.8 --depth 2 --json
forge route calibrate --workload repair
```

The scoped router compares first verified attempts on common tasks with recorded prices, a current listing and matching provider deployment. It reports success, a 95% Wilson interval, cohort size and mean reported cost. The operator can specify `budget:USD`, `target:P` or `value:USD`. For a cascade the replay charges each reached attempt. The operator reports the model and cost. The verifier authenticates the verdict against the checkout and code state. `forge route fit` updates the offline benchmark fit with authenticated local outcomes.

Use `--schema 1` for the historical family table. A configured top-model authorization can prevent automatic selection of that specific deployment.

## Offline benchmark comparison

`forge route universal "<task>"` with no provider compares historical fitted models using a multidimensional item-response model. Three observed prompt measurements, estimated success and fitted costs determine which candidate sequences meet the objective. On 350 held-out SWE-bench tasks the router solved 80.0% at $0.128 per task. A fixed cascade chosen on development data solved 80.6% at $0.136.

## Providers and cost

```bash
forge config               # show / switch / add providers, set the default model
forge cost                 # real per-day spend
forge cost --stages        # measured per-stage cost factors
```

<Note>
  `forge cost --stages` reports **measured stages only** — a stage with no events says
  "no data", never a default. A number is an assumption until measured. A day or stage with
  no logs is **unknown, not $0**; spend figures are estimates (logged tokens × list price,
  USD), and a model without a price is "unpriced", not free.
</Note>
