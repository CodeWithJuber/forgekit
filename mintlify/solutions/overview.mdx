## How solutions ship

Every solution follows the same contract, so you can trust the pattern even
before you trust any single feature:

1. **One pain point per release** — prioritized from real-world agent failures
   (see `docs/STRATEGY_2026.md` §7), never a grab-bag.
2. **Runnable example** — `examples/<name>/` with copy-paste steps that run in
   a scratch directory. No API keys, no cloud.
3. **Demo GIF** — rendered from captured real CLI output, never hand-drawn.
4. **Adversarial proof where it matters** — guardrail claims ship with the
   attacks that tried to break them (`forge doctor --adversarial`).
