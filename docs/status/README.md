# Claim status

Every load-bearing headline this project makes — about the product, the research, and the
numbers behind both — with its current status and the evidence behind it. The source of truth is
the machine-readable registry [`claims.json`](claims.json); the table below is generated from it.

**Statuses**

| Status | Meaning |
| --- | --- |
| `implemented` | the code exists and does what the claim says; tests exercise it |
| `measured` | a number produced by a stated procedure on stated data, reproducible from this repository |
| `partial` | some of the claim holds; the notes say which part does not |
| `reported` | stated by someone (this project included) with evidence this repository cannot reproduce end to end |
| `hypothesis` | not tested yet: a target or an assumption |
| `refuted` | tested and false as stated; the notes give the counterexample and any corrected wording |

**Rules**

- A headline that is not `measured` or `implemented` is never quoted as an achievement. A cost
  figure also needs the fields in
  [plan 05 §3](../plans/substrate-v2/05-cost-model.md#3-acceptance-rule-for-any-cost-headline).
- `source_commit` is the commit a status was assessed against (here, `d2abfa6`, the commit an
  external review pinned on 2026-09-26). Several claims marked `refuted` there have fixes in the
  later commit `aedddf5`, which the notes name; a status changes only after the claim is
  re-assessed against the new code, and `source_commit` moves with it. The universal-router rows
  also use results produced on 2026-09-26 with this repository's own scripts
  (`bench/universal-router/`), which the notes date.
- Edit [`claims.json`](claims.json), then run `node scripts/claims-status.mjs` to regenerate this
  table. `node scripts/claims-status.mjs --check` fails on an invalid registry, a stale table, or
  a `docs/cognitive-substrate/` copy that has drifted from its canonical source in `research/`.

The registry exists because the project's own rule — *do not assert without evidence* — needed a
place where every assertion's evidence can be looked up.
