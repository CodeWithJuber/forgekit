---

The #1 churn driver for agent coding tools is billing opacity — a run that
quietly burns $40 while you watch the spinner. Forge treats spend as a
first-class guardrail.

<img src="/images/cost-governance.gif" alt="Terminal recording of configuring a spend budget, reading the status and inspecting the guard decision." />

## How it works

```bash
forge budget set --daily 10 --per-task 2 --alert-at 0.8 --hard
forge budget status
forge budget check --session-id <sid>
```

- **Two limbs** — a per-day ceiling and a per-task (session) ceiling. The guard
  snapshots spend at session start and measures the delta.
- **Alert threshold** — past `--alert-at` (default 80%) the guard nudges the
  agent with context instead of nagging every call (spend is checked 1 in 100
  tool calls).
- **Opt-in hard breaker** — `--hard` turns over-budget from "ask" into "deny".
  Without it, over-budget is advice, never a block.
- **The honesty rule** — unknown spend never alerts and never blocks. No
  telemetry, no verdict; the command says so plainly.

`FORGE_COST_CEILING` overrides the daily budget when set; unset, a historic
$10/day soft ceiling applies.

## Try it

The [cost-governance example](https://github.com/CodeWithJuber/forgekit/tree/master/examples/cost-governance)
runs the whole flow in a scratch directory — set a budget, inspect it, and ask
the guard for a verdict, exactly as the agent sees it mid-run.
