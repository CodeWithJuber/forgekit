## Install the CLI

Use Node.js 20 or later. For supervised runs install Python 3.11+ with SQLite outside the project. Document extraction may need additional programs for the formats you use.

```bash
npm install -g @codewithjuber/forgekit
forge doctor
```

For features from the repository ahead of a registry release, install the source build with `npm install -g github:CodeWithJuber/forgekit`.

## Connect your coding host

Run the commands in the project where your agent works.

| Host | Setup |
| --- | --- |
| Claude Code | Run `forge init --tools claude` and `forge hooks on --hosts claude` in the checkout. Open Claude Code, trust the project and enable the project MCP server if prompted. The optional native plugin can also be installed from the ForgeKit marketplace. |
| Kimi Code | Run `forge init --tools kimi` and `forge hooks on --hosts kimi`. In Kimi, trust the workspace, run the printed `/plugins install` command and then `/reload`. Kimi reads the project MCP entry from `.kimi-code/mcp.json`. |
| Local Codex | Run `forge init --tools codex` and `forge hooks on --hosts codex`. In a trusted project, review the hooks with `/hooks`. The Codex plugin also bundles native hooks, skills and MCP configuration. |
| Another stdio MCP client | Register a server named `forge-cortex` with command `forge` and arguments `["cortex-mcp"]`. Start it in the project directory or supply the project's absolute path through `FORGE_ROOT`. |

For gated model and tool execution, follow [supervised project setup](/guides/supervised-runs). The [host matrix](https://github.com/CodeWithJuber/forgekit/blob/master/docs/INTEGRATIONS.md) describes the events available in each client.

## Contributor setup

```bash
git clone https://github.com/CodeWithJuber/forgekit.git
cd forgekit
npm link
```

Alternatively, run `bash install.sh` inside the checkout for the symlink installer. After installation, run `forge doctor` in the project you want to work on.

## Updates

```bash
forge update --check
forge update
forge update --to <version>
```

Continue with the [project quickstart](/quickstart).
